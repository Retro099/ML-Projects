## 日本語要約
日本語のレビューやテキストに対する感情分析モデルを構築しました。Hugging Face Transformers + PyTorchを使用してBERTをファインチューニングし、Positive / Negative / Neutralの3クラス分類を実現。eコマース顧客満足度分析や自動レビュー分類に活用可能です。GradioデモとStreamlit Cloudデプロイ済みです。
